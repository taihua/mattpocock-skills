# 階段邊界（Phase boundaries）

**階段（phase）**是 session 中的一段工作：拷問、實作、QA。這個定義是刻意模糊的：當你心想*「好，那部分我們完成了」*時，一個階段就結束了。

**階段邊界**是兩個階段之間的空隙，而它是這個決策唯一該發生的地方。在階段中途沒有決策要做：繼續，或把剩下的工作拆給子代理。在階段中途壓縮會讓 agent 失去頭緒。

## 五個選項

| 選項           | 它做什麼                                         |
| -------------- | ------------------------------------------------ |
| **Continue（繼續）** | 留在 session 中。完全沒有情境切換。              |
| **`/clear`**   | 清空 context window，從零開始。                  |
| **`/handoff`** | 寫出一個可攜的 markdown 檔，並在任何地方以它作為新 session 的起點。 |
| **Subagent（子代理）** | 把任務送到它自己的 context window，並取回一份報告。 |
| **`/compact`** | 壓縮這個情境，並以摘要作為新 session 的起點。     |

## 決策樹

在邊界上由上往下走。第一個**是**勝出。

**1. 你能在這個 session 中繼續嗎？** 有兩件事會讓答案為是：下一個階段需要這個階段作為**第一手資料（primary source）**，或者你還剩下足夠的[聰明區（smart zone）](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（約 15 萬 token）讓下一個階段放得進去。拷問 → 實作是標準的「是」：實作需要逐字的推理過程，而不是它的摘要。繼續不花任何成本，也不失去任何東西，所以在考慮其他任何選項之前，要先排除它。

**2. 這個情境與接下來的事無關嗎？** 這個 session 中的一切（探索、決策、死路）都可以丟掉嗎？如果是，就 **`/clear`**。這是整個棋盤上最便宜的一步：它不花任何時間，並把整個視窗還給你。`/clear` 也不是終點：舊的 session 仍然可以恢復。

判斷錯誤的代價是單向的。清掉一個*相關的*情境，你就會失去你所建造之物背後的**為什麼**，而且再怎麼回頭讀 diff 也找不回來。

**3. 你需要交接嗎？** `/handoff` 的用途很狹窄。只有在以下情況你才需要它：

- 換到一個**新的 harness**（Claude → Codex），
- 移到一個**新的目錄**或 repo，
- 把工作交給一位**同事**，
- 或者在**階段中途**發現了一個支線任務，想把它分岔出去，又不想打斷你正在做的事。

這份清單就是這一條的全部。`/handoff` 買到的是**可攜性**：一個可以帶著走的檔案。如果沒有任何東西要帶走，你就不需要它。

**4. 這個任務能離線（AFK）完成嗎？** 它的範圍是否夠緊縮，可以在你離開鍵盤、不需要引導的情況下執行？那就把它送給一個**子代理**，讓這個 session 保持原樣。自動化審查是標準的例子：agent 讀 diff 並回報，在它執行期間不需要你。

**5. 否則，就 `/compact`。** 相關的情境、相同的 harness、相同的目錄，而你需要留在迴圈中：這就是決策樹的落點，而且很常落在這裡。給它一個指示（`/compact we're going to QA this area`），讓摘要保留下一個階段需要的東西。

`/compact` 是**預設值，而不是第一個選擇**。它位於最底端，因為上面四個問題都更便宜或更精確。人們一開始就選它時的失敗模式，是一個新的 session 對某個被摘要壓扁的決策充滿自信地搞錯。

## 第一手資料與二手資料

除了**繼續**之外，每一步都會把一份**第一手資料**變成一份**二手資料**：原本實際發生過的 session，被它的摘要所取代。這個交換永遠是同樣的形狀：

| 來源                                | 資訊   | 雜訊 | 活動空間 |
| ----------------------------------- | ------ | ---- | -------- |
| 第一手（Continue）                  | 完整   | 很多 | 很少     |
| 二手（`/compact`、`/handoff`）      | 有損失 | 較少 | 很多     |

這就是為什麼問題 1 排在第一位。只有在留下來的成本高於它帶來的好處時，你才需要承擔這份損失。

## 這些都是判斷題

這些問題並不客觀：每一個都帶有個人品味，同一個邊界在不同的日子可能有兩種走法。價值在於**依序**問它們，而且是在邊界上問，而不是在工作進行到一半時。
