name: research
description: 以高可信度的第一手資料調查一個問題，並把發現整理成 repo 中的一份 Markdown 檔。當使用者想研究某個主題、蒐集文件或 API 的事實，或想把閱讀的跑腿工作交給背景 agent 時使用。
---

啟動一個**背景 agent（background agent）**來做研究，讓你在它閱讀的同時繼續工作。以全新的 context window 啟動它。

它的工作：

1. 以**第一手資料**（官方文件、原始碼、規格、第一方 API）調查這個問題，而不是看別人整理過的二手文章。每一個主張都要追溯回擁有它的原始來源。
2. 把發現寫進單一份 Markdown 檔，並為每個主張註明來源。
3. 存到 repo 原本就存放這類筆記的地方；遵循既有的慣例，如果沒有慣例，就放在合理的位置並說明放在哪裡。
