# 分類標籤（Triage Labels）

這些 skill 以五個標準分類角色來表達。這個檔案把這些角色對應到這個 repo 的 issue tracker 中實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 我們 tracker 中的標籤 | 意義                         |
| -------------------------- | --------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`        | 需要維護者評估這個 issue     |
| `needs-info`               | `needs-info`          | 等待回報者提供更多資訊       |
| `ready-for-agent`          | `ready-for-agent`     | 已完整定義，可交給離線 agent |
| `ready-for-human`          | `ready-for-human`     | 需要人來實作                 |
| `wontfix`                  | `wontfix`             | 不會處理                     |

當 skill 提到某個角色時（例如「套用 AFK-ready 分類標籤」），使用這張表中對應的標籤字串。

編輯「我們 tracker 中的標籤」這一欄，讓它符合你實際使用的詞彙。
