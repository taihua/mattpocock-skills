# GLOSSARY.md 格式

`GLOSSARY.md` 是這個教學工作區的標準用語。所有講解、練習與學習紀錄都應遵循其中的術語。建立它本身就是學習的一部分：能把一個概念壓縮成精準的定義，就是使用者理解它的證據。

## 結構

```md
# {主題} Glossary

{用一到兩句話描述這份 glossary 涵蓋的主題。}

## Terms

**Hypertrophy（肌肥大）**:
在反覆的訓練中，由機械張力與代謝壓力所驅動的肌肉生長。
_Avoid（避免使用）_: Bulking、getting big

**Progressive overload（漸進式超負荷）**:
透過負重、訓練量或強度，隨時間有系統地增加肌肉所承受的需求。
_Avoid（避免使用）_: Pushing harder、levelling up

**RPE (Rate of Perceived Exertion，自覺強度)**:
以 1 到 10 自我評估一組動作有多吃力，10 代表力竭，8 代表還剩兩下的餘力。
_Avoid（避免使用）_: Effort score、intensity rating
```

## 規則

- **只有在使用者理解某個術語後才加入。** Glossary 是壓縮後知識的紀錄，不是讓使用者拿來學習的字典。如果使用者才剛接觸某個概念，要等到他能正確使用它之後，才把它提升到這裡。
- **要有主見。** 當同一個概念有好幾種說法時，選出最好的一個，其餘列為應避免的別名。語言就是這樣被壓縮的。
- **定義要精簡。** 一到兩句話。定義這個術語「是什麼」，而不是它「做什麼」或「怎麼做」。
- **在定義中使用 glossary 本身的術語。** 一旦某個術語進入 glossary，就在各處優先使用它，包括其他術語的定義中。這能讓之後的複雜術語更容易理解。
- **自然形成群組時，用子標題分組**（例如 `## Anatomy`、`## Programming`）。如果術語彼此連貫，用平鋪的清單也可以。
- **明確標註歧義。** 如果某個術語在更廣的領域中用法鬆散，要註明這裡的解讀方式：「在這個工作區中，『set』一律指正式組；熱身組另外記錄。」
- **隨著理解加深而修訂。** 使用者第一週寫下的定義，到第六週可能就是錯的。直接原地更新；不要留下過時的條目。
